## 已确定的实现边界

- Main pool 的 16 个全注意力层共享逻辑页状态。页号保留原始位置，只驱逐全部层回写完成的 Both 页；sink 始终驻留。
- 每块发布同一版本的块表、按逻辑位置升序的混合访问列表和 key 前缀和。prefill 每层一遍，decode 至多两遍。
- staging 按一层最大流式量加 64 MiB 在加载期规划；访问元数据和 partial scratch/state 同样一次分配，不与 GDN 暂存重叠。
- dense 路径保持原分派和预算；本步 MTP pool 保留完整 dense 容量。tiered 限 C=1，关闭磁盘状态缓存、turn checkpoint、retained resume 并说明原因。
- BF16 tiered 只保证功能，不承诺性能。隐藏影子校验默认关闭，关闭时不增加 shadow 读回、同步或分配。
